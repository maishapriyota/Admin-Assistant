Admin Assistant

Ask questions about city service documents. Personal data is removed before anything is processed, every answer cites its source, and questions the documents can't answer are refused instead of guessed.

Ask a question to see the passages used.

This shows exactly what would be sent to a language model, after redaction.

With Ollama, start it with OLLAMA_ORIGINS=* so the browser may call it. OpenAI-compatible URLs end in /v1. If the model call fails, the app falls back to the offline answer.

All documents are fictional (Musterstadt is invented) and written for this demo. Replace them in the DOCS array with real public documents.
